Constants Reference

TryCatch.au3 Constants

$FORCE_RESET Pass to _EndTry() to reset the entire try/catch state regardless of nesting depth. For crash recovery and test teardown scenarios only - not for use in normal code. See Concepts - Force Reset.
$UNDEFINED_SOURCE The source value used in exception entries added by _TryWith(), where no specific function name is available. Returned in $e.sSource for such entries.
$DEFINED_ENTRY Stack entry type constant identifying entries added by _ThrowException() (named exceptions from compatible try/catch functions).
$UNDEFINED_ENTRY Stack entry type constant identifying entries added by _TryWith() (generic exceptions from non-compatible function calls).
$ROOT_TRYBLOCK Identifies the root-level try scope in stack trace inspection.

Exception.au3 Constants

$EXCEPTION_ROOT The string name of the root exception type: "TryCatchException". Every exception type registered without an explicit parent automatically extends "TryCatchException". This name is reserved and cannot be used as a name in _RegisterException(). It can be used as the $sParent argument to explicitly root a type at the top of the hierarchy, or passed to _Catch() as a catch-all (equivalent to omitting the type argument entirely).
