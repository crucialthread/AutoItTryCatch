Function Reference

Try/Catch Control Flow

_TryOpens a try scope and activates the exception stack for the enclosed code.
_EndTryCloses the current try scope.
_CatchChecks the current scope's stack for a matching exception entry and returns True if found.
_AsExceptionTypeNormalizes an exception type specification (single name, comma-separated list, or array) for use with _Catch().

Compatible Try/Catch Functions

These two functions work together to build compatible try/catch functions - functions that participate fully in the exception model by skipping their work when a prior exception is already on the stack.

_OnErrorResumeReturns True if exceptions exist on the current scope's stack. Used as the skip guard at the start of every compatible try/catch function.
_ThrowExceptionAdds a named exception entry to the current scope's stack. Used inside compatible try/catch functions to signal failure.

Non-Compatible Function Integration

These two functions work together to integrate non-compatible functions (those using @error/SetError()) into the exception model.

_TryWithWraps a non-compatible function call and converts a non-zero @error into a generic exception entry on the stack.
_NoErrReturns True if no exceptions exist on the stack. Used with _TryWith() to make non-compatible functions skip when a prior exception exists.

Stack Inspection

_StackTraceReturns the current scope's exception entries, optionally passing them through a handler function.
_FormatStackTraceFormats exception stack entries as a human-readable string.

Exception Registry

_RegisterExceptionRegisters a named exception type in the global exception registry.
_GetExceptionMessageReturns the registered default message for a named exception type.
_GetExceptionCodeReturns the numeric code associated with a named exception type.
_GetExceptionParentReturns the parent type name of a named exception type.
_IsExceptionExistsReturns True if a named exception type is registered.
_IsExceptionOfReturns True if a named exception type is equal to or descends from another type.
_ExtendsExceptionReturns True if a named exception type directly or indirectly extends another type.
_AsErrCodeResolves an exception code - validates a provided code or returns the next auto-incremented value.
