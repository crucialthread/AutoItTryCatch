Getting Started

Installation

Download the installer from the releases page and run it. The installer copies TryCatch.au3 and Exception.au3 to your AutoIt include directory. Only one include is needed in your scripts - TryCatch.au3 includes Exception.au3 automatically:

#include <TryCatch.au3>

For Git projects, see the README for instructions on using the solution as a Git submodule.

How This Solution Works

Unlike traditional try/catch in languages like C# or Java, this solution does not halt execution and jump to a catch handler when an error occurs. The script always continues executing line by line.

Instead, the solution works through compatible try/catch functions - functions that check whether a prior exception is already on the stack at the start of their execution, and if so, skip their work and return immediately. When all functions in a try block are compatible (or decorated with _TryWith(_NoErr() ? ... : Null)), the net effect is identical to a traditional try/catch: after any exception, subsequent functions are silently skipped until _Catch() handles the exception.

Key point: only compatible try/catch functions and _TryWith(_NoErr() ? ... : Null) decorated calls skip execution on a prior exception. Regular AutoIt functions and plain _TryWith(func()) calls always execute regardless of prior exceptions on the stack.

Writing a Compatible Try/Catch Function

A compatible try/catch function is a regular AutoIt function that uses _OnErrorResume() and _ThrowException() to participate fully in the exception model: 

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadConfig($sPath)
    ; Skip if a prior exception is already on the stack
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)

    ; Throw a named exception on failure
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Config not found: " & $sPath, _ReadConfig), 0, False)
    EndIf

    Return FileRead($sPath)
EndFunc

The pattern for throwing is always: Return SetError(_ThrowException("ExceptionName", "message", _FuncName), 0, False)

Your First Try/Catch Block

The most common and recommended pattern combines compatible try/catch functions with _TryWith(_NoErr() ? ... : Null) for non-compatible functions: 

#include <TryCatch.au3>

_RegisterException("MyException",      "Something went wrong")
_RegisterException("AnotherException", "Something else went wrong")

_Try()

    ; --- Compatible try/catch function (preferred) ---
    ; Skips automatically if any previous function in this scope already threw.
    _MyCompatibleFunc()

    ; --- Non-compatible function wrapped with _TryWith() + _NoErr() ---
    ; Skips if any prior exception exists on the stack.
    ; Captures @error as a generic exception if the function fails.
    _TryWith(_NoErr() ? _AnyNonCompatibleFunc($param) : Null)

    ; --- Plain _TryWith() without _NoErr() ---
    ; Always runs regardless of prior exceptions on the stack.
    ; Use when you always want the call to run and capture its own @error independently.
    _TryWith(_AnotherNonCompatibleFunc($param))

Local $e
If _Catch($e, _AsExceptionType("MyException")) Then
    ConsoleWrite("MyException: " & $e.sMessage & @CRLF)
ElseIf _Catch($e, _AsExceptionType("AnotherException")) Then
    ConsoleWrite("AnotherException: " & $e.sMessage & @CRLF)
ElseIf _Catch($e) Then
    ; Catch-all - catches any exception including generic ones from _TryWith()
    ConsoleWrite("Unexpected error: " & $e.sException & " - " & $e.sMessage & @CRLF)
EndIf

_EndTry()

The Exception Object

When _Catch() returns True, the variable receives the caught exception with three properties:

$e.sExceptionThe exception type name (e.g. "FileException").
$e.sMessageThe exception message.
$e.sSourceThe source of the throw - the function name for compatible function entries, or $UNDEFINED_SOURCE for _TryWith() entries.

Wrapping Non-Compatible Functions

When you need to use AutoIt built-in functions or third-party UDFs that signal errors via @error/SetError(), use _TryWith() to capture their errors as exceptions.

_TryWith() captures @error automatically at the call site. With the _NoErr() guard, it also skips the call if a prior exception is already on the stack - making it behave like a compatible function: 

_Try()
    ; _TryWith with _NoErr() - skips if prior exception exists, captures @error as exception
    Local $sContent = _TryWith(_NoErr() ? FileRead("config.ini") : Null)
    _TryWith(_NoErr() ? ConsoleWrite("Read " & StringLen($sContent) & " bytes" & @CRLF) : Null)

Local $e
If _Catch($e) Then
    ConsoleWrite("Could not read config file" & @CRLF)
EndIf
_EndTry()

Early Return from a Try Block

If you need to Return from inside a try block, always call _EndTry() first. Two supported patterns: 

; Pattern 1 - Return _EndTry() on one line
Func _MyFunc()
    _Try()
        If SomeCondition() Then Return _EndTry()
    Local $e
    If _Catch($e) Then ; ...
    EndIf
    _EndTry()
EndFunc

; Pattern 2 - _EndTry() then Return on separate lines
Func _MyFunc($vValue)
    _Try()
        If SomeCondition() Then
            _EndTry()
            Return $vValue
        EndIf
    Local $e
    If _Catch($e) Then ; ...
    EndIf
    _EndTry()
EndFunc
Warning: never use a bare Return from inside a try block without calling _EndTry() first. Doing so corrupts the internal depth counter and causes unpredictable behavior. The TryCatchLint tool detects this mistake automatically.
