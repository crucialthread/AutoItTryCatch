Function Reference

_TryWith

Wraps a non-compatible function call and converts a non-zero @error into a generic exception entry on the stack.

#include <TryCatch.au3>
_TryWith ( $vReturn [, $iError = @error] )

Parameters

$vReturnThe return value of the wrapped function call. Pass the function call directly as this argument.
$iError[optional] The @error value to evaluate. Defaults to @error captured automatically at the call site - in most cases this argument should not be passed explicitly.

Return Value

AlwaysReturns $vReturn unchanged. If $iError was non-zero, a generic exception entry (type "TryCatchException", source $UNDEFINED_SOURCE) is added to the scope's stack before returning.

Remarks

_TryWith() integrates AutoIt built-in functions and third-party UDFs that signal errors via @error/SetError() into the exception stack, without modifying those functions.

Plain _TryWith() always runs regardless of whether exceptions already exist on the scope's stack. This is the key difference from compatible try/catch functions. It adds its own entry independently: 

; This always executes, even if a prior exception exists on the stack
_TryWith(SomeFunc())

To make _TryWith() behave like a compatible function - skipping its execution if a prior exception is on the stack - combine it with _NoErr(). This is the preferred pattern: 

; Skips if prior exception exists on the stack, captures @error if it runs and fails
_TryWith(_NoErr() ? SomeFunc() : Null)

Because $iError defaults to @error, AutoIt captures the error value automatically at the call site. The function call and the error capture happen in one expression - never split them across lines: 

; Correct - @error captured automatically at the call site
Local $sContent = _TryWith(FileRead("config.ini"))

; Wrong - @error is already reset to 0 by the time the second line runs
Local $sContent = FileRead("config.ini")
_TryWith($sContent)

Generic entries added by _TryWith() use "TryCatchException" as the exception type and $UNDEFINED_SOURCE as the source, which distinguishes them from named entries added by _ThrowException() in stack trace inspection.

Example

#include <TryCatch.au3>

_Try()
    ; Preferred: _TryWith + _NoErr() - skips if prior exception, captures @error if it runs
    Local $sContent = _TryWith(_NoErr() ? FileRead("config.ini") : Null)

    ; The next line also uses _NoErr() so it skips if FileRead failed above
    _TryWith(_NoErr() ? ConsoleWrite("Read " & StringLen($sContent) & " bytes" & @CRLF) : Null)

Local $e
If _Catch($e) Then
    ConsoleWrite("Failed: " & $e.sSource & @CRLF)
EndIf
_EndTry()

Example - plain _TryWith() (always runs)

#include <TryCatch.au3>

_Try()
    ; This always runs regardless of any prior exceptions on the stack
    Local $sContent = _TryWith(FileRead("config.ini"))

    ; This also always runs - if FileRead failed, $sContent may be empty/invalid
    ; Use _NoErr() guard above to prevent this
    ConsoleWrite("Length: " & StringLen($sContent) & @CRLF)

Local $e
If _Catch($e) Then
    ConsoleWrite("Caught generic exception" & @CRLF)
EndIf
_EndTry()
