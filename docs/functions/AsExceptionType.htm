Function Reference

_AsExceptionType

Normalizes an exception type specification into an array for use with _Catch().

#include <TryCatch.au3>
_AsExceptionType ( $vException )

Parameters

$vExceptionAccepts three forms:

- A single name: "FileException"
- A comma-separated list: "FileException,NetworkException"
- An already-built array: passed through unchanged

Order matters in comma-separated lists - the first type listed is checked first.

Return Value

SuccessA 0-based array of exception type name strings, suitable for passing to _Catch().

Remarks

Using _AsExceptionType() is the recommended pattern when specifying exception types for _Catch(), even for a single type. It improves readability and makes all _Catch() calls consistent in style: 

; Recommended - consistent and readable
_Catch($e, _AsExceptionType("FileException"))
_Catch($e, _AsExceptionType("FileException,NetworkException"))

; Also valid - bare string accepted by _Catch() for single types
_Catch($e, "FileException")

List order beats recency: when a comma-separated list is used, the type listed first is checked first, regardless of which exception was added most recently to the stack. This makes matching order explicit and predictable.

Related

_Catch

Example

#include <TryCatch.au3>

_RegisterException("IOException",      "An I/O operation failed")
_RegisterException("FileException",    "A file operation failed",    "IOException")
_RegisterException("NetworkException", "A network operation failed", "IOException")

Func _ReadFile($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadFile), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadFile("config.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ; Single type - _AsExceptionType recommended even here
    ConsoleWrite("File error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e, _AsExceptionType("FileException,NetworkException")) Then
    ; Multiple types - _AsExceptionType required
    ConsoleWrite("I/O error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e) Then
    ConsoleWrite("Unexpected: " & $e.sException & @CRLF)
EndIf
_EndTry()
