Function Reference

_OnErrorResume

Returns True if exceptions exist on the current scope's stack. Used as the skip guard in compatible try/catch functions.

#include <TryCatch.au3>
_OnErrorResume ( )

Parameters

None.This function takes no parameters.

Return Value

TrueExceptions exist on the current scope's stack and a try scope is active. The compatible function should skip its work and return immediately.
FalseNo exceptions on the stack, or no try scope is active. The function should proceed normally.

Remarks

_OnErrorResume() and _ThrowException() work together to build compatible try/catch functions - functions that participate fully in the exception model. _OnErrorResume() is always the first statement in a compatible function: 

Func _MyCompatibleFunc()
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    ; ... rest of function only executes if no exceptions on the stack
EndFunc

When a try scope is active and exceptions exist on its stack, all compatible functions that check _OnErrorResume() skip their work and return immediately. This is what creates the "skip remaining functions after a failure" behavior that makes the solution work like a traditional try/catch.

A compatible try/catch function can contain any number of instructions and throw any number of different exception types depending on what fails. There is no restriction on its complexity - it is a regular AutoIt function that happens to start with the _OnErrorResume() guard and uses _ThrowException() to signal failures.

Note that _OnErrorResume() checks for exceptions on the stack, not AutoIt's @error. It is independent of AutoIt's native error system.

Example

#include <TryCatch.au3>

_RegisterException("FileException",    "A file operation failed")
_RegisterException("NetworkException", "A network operation failed")

Func _ReadConfig($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadConfig), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

Func _SendConfig($sContent)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    ; ... _ReadConfig threw, so this function is skipped entirely
    If $sContent = "" Then
        Return SetError(_ThrowException("NetworkException", "Nothing to send", _SendConfig), 0, False)
    EndIf
    ; ... send $sContent ...
EndFunc

_Try()
    _ReadConfig("missing.ini")  ; throws FileException
    _SendConfig("")             ; skipped - _OnErrorResume() returns True
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite("File error: " & $e.sMessage & @CRLF)
EndIf
_EndTry()
