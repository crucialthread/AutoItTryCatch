Function Reference

_Try

Opens a try scope and activates the exception stack for the enclosed code.

#include <TryCatch.au3>
_Try ( )

Parameters

None.This function takes no parameters.

Return Value

None.This function does not return a meaningful value.

Remarks

Opens a new try scope and initializes its exception stack. All compatible try/catch functions and _TryWith(_NoErr() ? ... : Null) calls within this scope will check this stack and skip their execution if any exception entry is present.

Try blocks can be nested. Each _Try() opens one level and each _EndTry() closes one level. Inner scopes have their own independent exception stacks.

Every _Try() must have a corresponding _EndTry(). Failing to close a try scope corrupts the internal depth counter and causes unpredictable behavior. Use the TryCatchLint tool to detect unbalanced pairs.

If you need to Return from inside a try scope, always call _EndTry() first. See Getting Started for the supported early-return patterns.

Related

_EndTry, _Catch, _OnErrorResume, _ThrowException

Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadConfig($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadConfig), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadConfig("config.ini")
    _ReadConfig("settings.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite("Caught: " & $e.sMessage & @CRLF)
EndIf
_EndTry()
