Function Reference

_NoErr

Returns True if no exceptions exist on the current scope's stack. Used with _TryWith() to make non-compatible function calls skip when a prior exception exists.

#include <TryCatch.au3>
_NoErr ( )

Parameters

None.This function takes no parameters.

Return Value

TrueNo exceptions on the current scope's stack. Safe to proceed.
FalseExceptions exist on the current scope's stack.

Remarks

_NoErr() is the logical inverse of _OnErrorResume(). Its primary purpose is to enable _TryWith() to behave like a compatible try/catch function - skipping its wrapped call when a prior exception already exists on the scope's stack: 

_TryWith(_NoErr() ? SomeNonCompatibleFunc() : Null)

Without _NoErr(), plain _TryWith(SomeNonCompatibleFunc()) always runs regardless of prior exceptions. The _NoErr() guard provides the same skip-on-prior-exception behavior that _OnErrorResume() provides for compatible functions, making this the preferred pattern when wrapping non-compatible functions.

Like _OnErrorResume(), _NoErr() checks the exception stack, not AutoIt's @error. It is independent of AutoIt's native error system.

Related

_TryWith, _OnErrorResume

Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadFile($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadFile), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    ; Compatible function - skips on prior exception via _OnErrorResume()
    Local $sContent = _ReadFile("missing.ini")

    ; Non-compatible wrapped with _NoErr() - also skips on prior exception
    ; If _ReadFile threw, this is skipped entirely
    _TryWith(_NoErr() ? ConsoleWrite("Content: " & $sContent & @CRLF) : Null)

Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite("Caught: " & $e.sMessage & @CRLF)
EndIf
_EndTry()
