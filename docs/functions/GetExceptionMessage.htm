Function Reference

_GetExceptionMessage

Returns the registered default message for a named exception type.

#include <TryCatch.au3>
_GetExceptionMessage ( $sName )

Parameters

$sNameThe registered exception type name.

Return Value

SuccessThe default message string registered for this type.
FailureEmpty string and @error set if the name is not registered.

Related

_RegisterException, _GetExceptionCode, _GetExceptionParent

Example

_RegisterException("FileException", "A file operation failed")
ConsoleWrite(_GetExceptionMessage("FileException") & @CRLF)
; Output: A file operation failed
