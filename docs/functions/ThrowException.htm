Function Reference

_ThrowException

Adds a named exception entry to the current scope's stack. Used inside compatible try/catch functions to signal failure.

#include <TryCatch.au3>
_ThrowException ( $sName [, $sMessage = "" [, $sCaller = ""]] )

Parameters

$sNameThe exception type name to throw (e.g. "FileException"). If the name has not been registered via _RegisterException(), it is auto-registered. Use with care - unregistered names are often typos. The TryCatchLint tool warns about them.
$sMessage[optional] A specific message for this throw, overriding the registered default message. Typically includes context-specific details such as a file path or parameter value.
$sCaller[optional] The name of the function throwing the exception. Pass the function's own name here so the exception entry correctly identifies its source. Used to populate $e.sSource in the caught entry.

Return Value

SuccessReturns the exception's numeric code - the value specified in _RegisterException() for this type, or an auto-incremented code if none was specified. This return value is designed for inline use with SetError() in the compatible function throw pattern.
Outside a try scopeReturns 0. The entry is not added since no scope is active.

Remarks

_ThrowException() is designed to be used inside compatible try/catch functions together with _OnErrorResume(). Its primary purpose is to add a named exception entry to the scope's stack so that:

  • Subsequent compatible functions (checking _OnErrorResume()) skip their execution
  • Subsequent _TryWith(_NoErr() ? ... : Null) calls are also skipped
  • _Catch() can match and handle the exception by name

Always use the following pattern when throwing inside a compatible function: 

Return SetError(_ThrowException("ExceptionName", "message", _FunctionName), 0, False)

This single line throws the exception, records the calling function as the source, and returns from the function in one step. The return value of _ThrowException() (the exception's numeric code) becomes the @error value via SetError(), which compatible callers can inspect if needed.

Auto-registration: if the exception name has not been registered, _ThrowException() auto-registers it. Use with care since unregistered names are often typos. Always prefer explicit registration via _RegisterException().

Related

_OnErrorResume, _Catch, _RegisterException

Example

#include <TryCatch.au3>

_RegisterException("FileException",    "A file operation failed")
_RegisterException("ParseException",   "A parse operation failed")
_RegisterException("NetworkException", "A network operation failed")

; A compatible function can have multiple operations and throw different exceptions
; depending on what fails - there is no restriction on the number of instructions
; or the number of different exception types it may throw.
Func _LoadAndProcessConfig($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)

    ; First check - file existence
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Config not found: " & $sPath, _LoadAndProcessConfig), 0, False)
    EndIf

    ; Second check - file readable
    Local $sContent = FileRead($sPath)
    If @error Then
        Return SetError(_ThrowException("FileException", "Could not read: " & $sPath, _LoadAndProcessConfig), 0, False)
    EndIf

    ; Third check - content valid
    If StringLen($sContent) = 0 Then
        Return SetError(_ThrowException("ParseException", "Config file is empty: " & $sPath, _LoadAndProcessConfig), 0, False)
    EndIf

    ; Fourth check - required key present
    If Not StringInStr($sContent, "[Settings]") Then
        Return SetError(_ThrowException("ParseException", "Missing [Settings] section in: " & $sPath, _LoadAndProcessConfig), 0, False)
    EndIf

    Return $sContent
EndFunc

_Try()
    Local $sConfig = _LoadAndProcessConfig("config.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite("File error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e, _AsExceptionType("ParseException")) Then
    ConsoleWrite("Parse error: " & $e.sMessage & @CRLF)
EndIf
_EndTry()
