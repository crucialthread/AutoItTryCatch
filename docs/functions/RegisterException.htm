Function Reference

_RegisterException

Registers a named exception type in the global exception registry.

#include <TryCatch.au3>
_RegisterException ( $sName [, $sMessage = "" [, $sParent = "" [, $iCode = 0]]] )

Parameters

$sNameThe name for this exception type (e.g. "FileException"). Invalid identifier characters are stripped automatically. Cannot be empty after sanitization or equal to "TryCatchException" (the root type, which is reserved).
$sMessage[optional] A human-readable default message. If omitted or empty, falls back to the sanitized name itself.
$sParent[optional] The parent exception type name. If omitted, the type is rooted directly under "TryCatchException". If the parent has not been registered yet, it is auto-registered. Self-inheritance returns False.
$iCode[optional] A specific numeric code. If omitted or not a valid positive integer, an auto-incremented code is assigned.

Return Value

TrueRegistration succeeded.
FalseRegistration failed: name sanitized to empty, name is "TryCatchException" (reserved), or self-inheritance detected.

Remarks

Registration is typically done once at the top of a library or script, before any try/catch blocks execute. Registering an already-registered name overwrites the existing entry - the new message, parent, and code replace the old ones.

Name sanitization: invalid characters are stripped silently rather than rejected. For example, "My Exception!" becomes "MyException".

Message fallback: if $sMessage is omitted or empty, the message defaults to the sanitized name. Every registered exception always has a non-empty message.

Related

_ThrowException, _IsExceptionOf, _IsExceptionExists

Example

#include <TryCatch.au3>

; Register a hierarchy
_RegisterException("IOException",      "An I/O operation failed")
_RegisterException("FileException",    "A file operation failed",    "IOException")
_RegisterException("NetworkException", "A network operation failed", "IOException")

; Message falls back to name when omitted
_RegisterException("TimeoutException")
ConsoleWrite(_GetExceptionMessage("TimeoutException") & @CRLF) ; Output: TimeoutException

; Name sanitization
_RegisterException("My Exception!")
ConsoleWrite(_IsExceptionExists("MyException") & @CRLF) ; True

; Overwrite
_RegisterException("FileException", "Updated message")
ConsoleWrite(_GetExceptionMessage("FileException") & @CRLF) ; Updated message
