Function Reference

_ExtendsException

Returns True if a named exception type directly or indirectly extends another type.

#include <TryCatch.au3>
_ExtendsException ( $sName, $sParent )

Parameters

$sNameThe exception type name to test.
$sParentThe ancestor type to test against.

Return Value

True$sName is a direct or indirect descendant of $sParent.
False$sName does not descend from $sParent, or $sName equals $sParent (use _IsExceptionOf() for equality check).

Remarks

Unlike _IsExceptionOf(), this returns False when $sName equals $sParent. It strictly tests the inheritance relationship, not equality.

Related

_IsExceptionOf, _GetExceptionParent

Example

_RegisterException("IOException",   "An I/O operation failed")
_RegisterException("FileException", "A file operation failed", "IOException")

ConsoleWrite(_ExtendsException("FileException", "IOException") & @CRLF)   ; True
ConsoleWrite(_ExtendsException("FileException", "FileException") & @CRLF) ; False
ConsoleWrite(_ExtendsException("IOException",   "FileException") & @CRLF) ; False
