Function Reference

_StackTrace

Returns the current scope's exception entries, optionally passing them through a handler function.

#include <TryCatch.au3>
_StackTrace ( [$vHandler = Default] )

Parameters

$vHandler[optional] A function reference to call with the raw entries array and count, or omitted/Default to return the raw entries array directly. Accepts:

- _FormatStackTrace - the built-in formatter, returns a human-readable string
- Any custom function with the signature Func _CustomFunc($mEntries, $iCount) - receives the entries array and count, returns whatever the function returns

_FormatStackTrace can be used as a reference implementation when writing custom handler functions.

Return Value

No handlerReturns a 0-based array of exception entry objects for the current scope. Each entry has .sException, .sMessage, and .sSource properties.
With handlerReturns whatever the handler function returns.
Incompatible handlerReturns False with @error = 0xDEAD.

Remarks

The most common usage is to pass _FormatStackTrace as the handler to get a formatted, human-readable string of the scope's exception entries directly: 

Local $sReport = _StackTrace(_FormatStackTrace)
ConsoleWrite($sReport & @CRLF)

Related

_FormatStackTrace, _Catch

Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadFile($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadFile), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadFile("missing.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ; Get formatted stack trace
    ConsoleWrite(_StackTrace(_FormatStackTrace) & @CRLF)

    ; Or get the raw array
    Local $aEntries = _StackTrace()
    ConsoleWrite("Entries in scope: " & UBound($aEntries) & @CRLF)
EndIf
_EndTry()
