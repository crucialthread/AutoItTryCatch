Function Reference

_EndTry

Closes the current try scope.

#include <TryCatch.au3>
_EndTry ( [$bForceReset = False] )

Parameters

$bForceReset[optional] Pass $FORCE_RESET to reset the entire try/catch state regardless of nesting depth. Default is False (close exactly one level). See Remarks.

Return Value

None.When used as Return _EndTry(), the enclosing function returns the default value for its return type.

Remarks

Closes the most recently opened try scope. Every _Try() must have exactly one corresponding _EndTry().

Early return pattern: if you need to return from inside a try scope, call _EndTry() before returning. Two supported patterns: 

; Pattern 1 - single line
If SomeCondition() Then Return _EndTry()

; Pattern 2 - separate lines (use when returning a specific value)
If SomeCondition() Then
    _EndTry()
    Return $someValue
EndIf
Warning - $FORCE_RESET: passing $FORCE_RESET resets the entire internal try/catch state to zero, regardless of how many try levels are currently open. This is an edge case for crash recovery or test teardown scenarios only. Do not use it as a substitute for properly balanced _Try()/ _EndTry() calls in normal code.

Related

_Try, _Catch, $FORCE_RESET

Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadConfig($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadConfig), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

; Early return pattern
Func _ProcessConfig($sPath)
    _Try()
        If Not FileExists($sPath) Then Return _EndTry()
        _ReadConfig($sPath)
    Local $e
    If _Catch($e, _AsExceptionType("FileException")) Then
        ConsoleWrite("Error: " & $e.sMessage & @CRLF)
    EndIf
    _EndTry()
EndFunc

_ProcessConfig("config.ini")
