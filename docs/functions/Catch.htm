Function Reference

_Catch

Checks the current scope's exception stack for a matching entry and returns True if found.

#include <TryCatch.au3>
_Catch ( ByRef $eOut [, $vType = ""] )

Parameters

$eOutA variable (passed ByRef) that receives the caught exception entry on match. The entry exposes three properties:

$eOut.sException - the exception type name
$eOut.sMessage - the exception message
$eOut.sSource - the function name that threw the exception, or $UNDEFINED_SOURCE for _TryWith() entries
$vType[optional] The exception type to match against. Accepts:

- A bare string: "FileException"
- A value from _AsExceptionType(): _AsExceptionType("FileException") or _AsExceptionType("FileException,NetworkException")
- Omitted or empty: catch-all, matches any exception (equivalent to matching "TryCatchException", the root type)

Type matching respects the exception hierarchy - catching a parent type also catches all descendant types.

Return Value

TrueA matching exception entry was found on the scope's stack and this scope has not already been matched. $eOut is populated with the latest matching entry.
FalseNo matching entry was found, or this scope has already been matched by a prior _Catch() call.

Remarks

Single match per scope: once a _Catch() call returns True in a given try scope, all subsequent _Catch() calls in the same scope return False. This ensures only one handler runs per scope and makes If/ElseIf chains work as expected.

Latest entry wins: when multiple exception entries exist on the scope's stack, _Catch() returns the latest one that matches the specified type.

List order when using _AsExceptionType(): when a comma-separated list is passed, the first type in the list is checked first, regardless of which exception was added most recently to the stack.

Using _AsExceptionType() is recommended even for single types, as it improves readability and consistency. A bare string is also accepted.

Related

_Try, _EndTry, _AsExceptionType, _OnErrorResume, _ThrowException

Example

#include <TryCatch.au3>

_RegisterException("IOException",      "An I/O operation failed")
_RegisterException("FileException",    "A file operation failed",    "IOException")
_RegisterException("NetworkException", "A network operation failed", "IOException")

Func _ReadFile($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadFile), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadFile("config.ini")
Local $e
If _Catch($e, "FileException") Then
    ; bare string - also valid
    ConsoleWrite("File error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e, _AsExceptionType("NetworkException")) Then
    ; _AsExceptionType - recommended pattern
    ConsoleWrite("Network error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e, _AsExceptionType("FileException,NetworkException")) Then
    ; multiple types in one handler
    ConsoleWrite("I/O error: " & $e.sMessage & @CRLF)
ElseIf _Catch($e) Then
    ; catch-all
    ConsoleWrite("Unexpected: " & $e.sException & @CRLF)
EndIf
_EndTry()
