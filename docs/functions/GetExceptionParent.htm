Function Reference

_GetExceptionParent

Returns the parent type name of a named exception type.

#include <TryCatch.au3>
_GetExceptionParent ( $sName )

Parameters

$sNameThe registered exception type name.

Return Value

SuccessThe normalized (lowercased) parent type key. Returns the normalized key of "TryCatchException" for top-level types.
FailureDefault if the name is not registered.

Remarks

Parent names are stored internally in normalized (lowercased) form. The value returned is the normalized key, not the original cased name used during registration.

Related

_RegisterException, _ExtendsException, _IsExceptionOf

Example

_RegisterException("IOException",   "An I/O operation failed")
_RegisterException("FileException", "A file operation failed", "IOException")

ConsoleWrite(_GetExceptionParent("FileException") & @CRLF)
; Output: ioexception  (normalized/lowercased)
