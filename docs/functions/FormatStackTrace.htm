Function Reference

_FormatStackTrace

Formats exception stack entries as a human-readable string.

#include <TryCatch.au3>
_FormatStackTrace ( $mEntries, $iCount )

Parameters

$mEntriesThe array of stack entries returned by _StackTrace().
$iCountThe number of entries in the array.

Return Value

SuccessA formatted multi-line string representing the exception stack entries, suitable for logging or display.

Remarks

Typically used by passing _FormatStackTrace as the handler argument to _StackTrace():

ConsoleWrite(_StackTrace(_FormatStackTrace) & @CRLF)

Related

_StackTrace

Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

Func _ReadFile($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Not found: " & $sPath, _ReadFile), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadFile("missing.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite(_StackTrace(_FormatStackTrace) & @CRLF)
EndIf
_EndTry()
