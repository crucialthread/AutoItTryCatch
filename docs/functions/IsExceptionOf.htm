Function Reference

_IsExceptionOf

Returns True if a named exception type is equal to or descends from another type.

#include <TryCatch.au3>
_IsExceptionOf ( $sName, $sType )

Parameters

$sNameThe exception type name to test.
$sTypeThe type to test against.

Return Value

True$sName is equal to or descends from $sType in the exception hierarchy.
False$sName is not equal to and does not descend from $sType.

Remarks

This is the same hierarchy check used internally by _Catch() to determine whether a thrown exception matches the requested type.

Related

_ExtendsException, _Catch, _RegisterException

Example

_RegisterException("IOException",   "An I/O operation failed")
_RegisterException("FileException", "A file operation failed", "IOException")

ConsoleWrite(_IsExceptionOf("FileException", "IOException") & @CRLF)   ; True
ConsoleWrite(_IsExceptionOf("FileException", "FileException") & @CRLF) ; True
ConsoleWrite(_IsExceptionOf("IOException",   "FileException") & @CRLF) ; False
