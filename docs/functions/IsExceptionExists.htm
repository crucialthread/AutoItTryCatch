Function Reference

_IsExceptionExists

Returns True if a named exception type is registered in the exception registry.

#include <TryCatch.au3>
_IsExceptionExists ( $sName )

Parameters

$sNameThe exception type name to check.

Return Value

TrueThe exception type is registered.
FalseThe exception type is not registered.

Related

_RegisterException, _IsExceptionOf

Example

_RegisterException("FileException", "A file operation failed")
ConsoleWrite(_IsExceptionExists("FileException") & @CRLF) ; True
ConsoleWrite(_IsExceptionExists("TypoException") & @CRLF) ; False
