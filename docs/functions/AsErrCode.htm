Function Reference

_AsErrCode

Resolves an exception code - validates a provided code or returns the next auto-incremented value.

#include <TryCatch.au3>
_AsErrCode ( [$iCode = Default] )

Parameters

$iCode[optional] An exception code to validate. If omitted or Default, returns the next auto-incremented code based on the registry size.

Return Value

SuccessReturns $iCode if it is a valid positive integer, otherwise returns the next auto-incremented code.

Remarks

_AsErrCode() is used internally by the exception registry to assign and validate numeric codes when registering exception types. It ensures every exception type always has a valid positive numeric code - either the one explicitly provided, or the next available auto-incremented value.
