Function Reference

_GetExceptionCode

Returns the numeric code associated with a named exception type.

#include <TryCatch.au3>
_GetExceptionCode ( $sName )

Parameters

$sNameThe registered exception type name.

Return Value

SuccessThe numeric code for this exception type.
Failure0 and @error set if the name is not registered.

Remarks

The numeric code is assigned at registration time - either the value explicitly provided to _RegisterException(), or an auto-incremented value.
