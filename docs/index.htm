AutoIt TryCatch Solution

The AutoIt TryCatch Solution brings structured exception handling to AutoIt, modeled after the try/catch/throw pattern found in modern programming languages. It consists of two libraries - TryCatch.au3 (which includes Exception.au3 automatically):

TryCatch.au3 The core try/catch engine. Provides _Try(), _Catch(), _EndTry(), _ThrowException(), _OnErrorResume(), _TryWith(), and supporting functions for writing exception-safe code.
Exception.au3 The exception type registry. Provides _RegisterException() and related functions for defining, querying, and navigating a typed exception hierarchy. Included automatically by TryCatch.au3.

A companion tool, TryCatchLint, provides static analysis to catch common mistakes before they reach runtime.

Key Features

Structured exception handling Write compatible try/catch functions that skip automatically when a prior exception is on the stack, keeping the happy path clean and grouping all failure handling in one place.
Compatible with existing code _TryWith() and _NoErr() let you integrate functions that use AutoIt's native @error/SetError() convention without modifying them.
Typed exceptions Define named exception types with an inheritance hierarchy. Catch specific types or entire families of related exceptions.
Stack trace _StackTrace() and _FormatStackTrace() let you inspect the current exception scope at any point during execution.
Static analysis The TryCatchLint tool checks for unbalanced _Try()/_EndTry() calls and unregistered exception name references before your code runs.

Quick Example

#include <TryCatch.au3>

_RegisterException("FileException", "A file operation failed")

; A compatible try/catch function - participates fully in the exception model
Func _ReadConfig($sPath)
    If _OnErrorResume() Then Return SetError(__GetStackCount(), 0, False)
    If Not FileExists($sPath) Then
        Return SetError(_ThrowException("FileException", "Config not found: " & $sPath, _ReadConfig), 0, False)
    EndIf
    Return FileRead($sPath)
EndFunc

_Try()
    _ReadConfig("config.ini")
    _ReadConfig("settings.ini")
Local $e
If _Catch($e, _AsExceptionType("FileException")) Then
    ConsoleWrite("Caught: " & $e.sException & " - " & $e.sMessage & @CRLF)
EndIf
_EndTry()
